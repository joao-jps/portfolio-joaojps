# Portfólio — João Paulo Santos

Portfólio pessoal em React, Vite e Tailwind CSS, com layout responsivo e capas de projeto desenhadas em CSS.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Atualização de projetos

Edite `src/projects.js` para adicionar, remover ou atualizar projetos. Cada item define nome, descrição, status, tecnologias, link do GitHub e tema visual (`wine`, `job`, `bank` ou `sushi`). Os currículos ficam em `public/cv/`.

## Build

```sh
npm run build
```
